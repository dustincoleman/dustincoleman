# Dustin Coleman

**Debugger platform engineer** — 15 years at Microsoft, seven of them on the Visual Studio Debugger.

I work at the intersection of developer tools and AI-assisted development. I was part of the Microsoft Research collaboration that brought conversational AI debugging into GitHub Copilot Chat, and these days I'm building AI-native developer tooling — MCP, RAG, and agentic patterns, with AI-assisted development as my daily working style.

## Selected work

- **[Pinnable Properties (Visual Studio 2019)](https://github.com/dotnet/roslyn/pull/38669)** — designed and implemented across the debugger's full stack, from the UI down through the Concord engine. The linked PR is the C# expression-evaluator result-provider implementation, merged into `dotnet/roslyn`.
- **Inline return values (Visual Studio 2022)** — architected the debugger-event-driven UI system that powers them, working across the Roslyn and editor teams.
- **[*Let's Fix this Together: Conversational Debugging with GitHub Copilot*](https://ieeexplore.ieee.org/document/10714559)** — IEEE VL/HCC 2024. A sustained research collaboration with Microsoft Research that shipped as production integration in GitHub Copilot Chat; named inventor on a related patent (pending).
